# SIH 2026 Fire Intelligence Demo

## Build
- Create a desktop-first disaster command center with Dashboard, Live Map, Event Analysis, Alerts, Reports, and Architecture views.
- Use realistic simulated hotspot records across India, with explicit Demo/Simulated Data labels throughout.
- Add shared navigation, search, time-range summaries, filters, selected-event details, and responsive layouts.

## Interactive workflow
- Add a prominent interactive India map with risk-colored markers and a detailed full-screen monitoring view.
- Implement deterministic classification, transparent risk calculations, animated “Run Risk Analysis,” and hotspot simulation.
- Add a judge-ready Demo Scenario stepper covering Detection → Classification → Risk → Alert → GIS Decision Support.
- Support alert acknowledgement and client-side report printing/downloading.

## Visual direction
- Use a dark navy command-center palette with restrained severity accents, high-contrast data surfaces, subtle grid/glass effects, and purposeful motion.
- Keep SIH 2026 and Team Solvix branding visible but compact.

## Technical details
- Keep all data and state in the frontend; no login, backend, or live service claims.
- Use Leaflet with OpenStreetMap tiles and a polished fallback if tiles fail.
- Add route-specific metadata and verify desktop and mobile presentation plus core interactions.
